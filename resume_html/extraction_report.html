四、抽取方法

1. 按 id 编码定位字段：这批 HTML 的字段 id 统一为 <板块前缀><字段代码><序号>（如 500375983JTIT1、UUID 版式同样成立）。JTIT/COMP/JSTD/EDDT/JDES = 职位/公司/起止/描述，DGRE/STUY/SCHO/GRYR = 学位/专业/学校/毕业年，FRFM/SKC = 自由文本与双栏技能。按「前缀 + 序号」把字段聚成一条记录，跨 267 种版式都不会错位。

2. 板块归一化：SECTION_ 后的代码取前 4 位大写字母，消除 EXPRc、SUMMa 这类副本后缀；共识别 35 类板块，主流为 EXPR(2492), SUMM(2484), NAME(2481), EDUC(2474), SKLL(2401), HILT(2252)。

3. 文本清洗：合并空白与 &nbsp;，按 li / p / br 分条，去除编辑器 UI 残留（"Examples"、"View Tips" 等）与匿名化占位符；HTML 实体解码，CSV 特殊字符正确转义。

4. 兜底召回：除结构化字段外，额外输出板块文本与逐条条目，保证自定义板块、无 id 的段落、破损标签里的内容也不丢失。

七、使用建议

· 想一张表看全部：直接用 resumes.csv，每份简历一行，各板块文本已合并。

· 想做结构化分析（任职年限、职位序列、学历分布）：用 resume_experiences.csv 与 resume_education.csv，按 resume_id 关联主表；start_year / end_year / grad_year 已提取为数值年份。

· 想做技能词表 / 全文检索：用 resume_items.csv，每行一个技能点或一条职责。

· 想结合版式模板：主表的 structure_family / layout_group 与上一轮的 structure_groups.csv、structure_report.html 对应。
