简历 HTML 结构相似性分组报告

扫描目录：resume_html/ ｜ 共 2484 个 HTML 片段 ｜ 原始文件未做任何改动

判定口径（可复现）

1. 用 DOM 解析每个文件，剥离所有正文文本、随机 id、内联 style，以及 b / u / i / font / br 等纯排版标签；只保留「标签名 + class 组合 + 层级」。

2. 折叠同构的重复子树（多段工作经历、多条技能列表等），消除经历条数造成的假差异，得到结构骨架指纹。

3. 指纹完全相同 → 精确版式组（267 组）；不同指纹之间计算节点 / 父子路径集合的 Jaccard 相似度，≥ 0.75 归入同一结构家族（57 族）。

4. 章节顺序（SECTION_NAME / SUMM / HILT / EXPR / EDUC / SKLL …）作为附加维度单独统计，不参与主聚类；另有 4 个视觉主题与标题边框等可解释标签。

相似度阈值 0.75 是严格口径：同族文件即便章节或经历条数不同，DOM 版式也基本一致。想更细可用「精确版式组」视图，想更粗可按 CSV 中的版式标签自行合并。

生成文件：structure_groups.csv（全量 2484 行清单）与本报告 structure_report.html。文件链接为相对路径：在 Finder 中双击本报告用浏览器打开即可跳转；若在 WorkBuddy 预览面板中链接不可用，请改用本地浏览器打开。
